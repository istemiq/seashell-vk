Деплой API (словарь + GigaChat + SQLite) на бесплатный/дёшевый хост
================================================================

Важно:
- VK Hosting отдаёт только ФРОНТ (папка build). API — отдельный сервис.
- После выкладки API нужно пересобрать фронт с адресом API:
  set VITE_API_URL=https://ВАШ-API-ХОСТ
  npm run build
  npm run deploy

Переменные окружения на сервере:
- GIGACHAT_API_KEY
- GIGACHAT_MODEL_NAME (например GigaChat-Max)
- PORT (часто задаёт хостинг сам)
- DATA_DIR=/data — если монтируете постоянный диск (рекомендуется)

------------------------------------------------------------
Вариант A — Render.com (Docker)
------------------------------------------------------------
1. Аккаунт на https://render.com
2. New → Web Service → подключить GitHub-репозиторий
3. Root: seashell/server (или собрать из подпапки)
4. Docker
5. Env: см. выше. Для SQLite на бесплатном тарифе диск иногда эфемерный —
   для важных данных лучше платный Persistent Disk или другой вариант.
6. URL вида https://xxx.onrender.com — его и подставить в VITE_API_URL

------------------------------------------------------------
Вариант B — Fly.io
------------------------------------------------------------
fly launch в папке server, добавить volume на /data, установить DATA_DIR=/data

------------------------------------------------------------
Вариант C — VPS (Oracle Free / Hetzner / Timeweb)
------------------------------------------------------------
Установить Node 22+, скопировать папку server, npm install, systemd unit,
nginx reverse proxy + HTTPS (Let's Encrypt). База в DATA_DIR на диске машины.

------------------------------------------------------------
Проверка
------------------------------------------------------------
