Политика конфиденциальности мини-приложения Seashell

Дата публикации текста: 9 мая 2026 г. Версия для пользователей ВКонтакте. Целевая аудитория мини-приложения:{' '} 16+ (школьный возраст — с согласия законных представителей и при самостоятельной оценке пригодности контента).

1. Кто обрабатывает данные

Мини-приложение Seashell (далее — «Приложение») обрабатывает персональные данные в объёме, необходимом для его работы. Оператором обработки является лицо, указанное владельцем мини-приложения в кабинете разработчика ВКонтакте (карточка приложения на dev.vk.com). Ниже — сведения о том, какие данные обрабатываются и с какой целью.

2. Какие данные мы получаем

  • Идентификатор пользователя ВКонтакте и параметры запуска мини-приложения (в том числе для проверки подлинности запросов к серверу Приложения), в соответствии с правилами платформы VK Mini Apps.
  • Содержимое словаря: введённые вами английские слова и фразы, сгенерированные краткие толкования и примеры, принадлежность слов к группам (названия групп), служебные идентификаторы записей в базе данных.
  • Разговорная практика: текст ваших реплик на английском и ответы сервиса, отправляемые в рамках одной сессии использования для формирования ответа (история диалога ограничена технически на стороне сервера).
  • Технические данные: обращения к API, время запросов, сообщения об ошибках — в минимальном объёме, необходимом для стабильной работы и защиты от злоупотреблений (в т.ч. ограничение частоты запросов).

Мы не просим и не обрабатываем намеренно пароль от вашего аккаунта ВКонтакте — вход выполняется через платформу VK.

3. Цели обработки

  • предоставление функций словаря (сохранение, отображение, группы, удаление слов);
  • генерация и обновление примеров и пояснений с помощью внешней языковой модели (GigaChat) по вашему запросу;
  • предоставление режима разговорной практики и короткой обратной связи по вашим фразам;
  • обеспечение безопасности (проверка подписи параметров запуска VK, ограничение частоты запросов);
  • исполнение требований законодательства при обращениях уполномоченных органов.

4. Правовые основания

Обработка осуществляется на основании исполнения пользовательского соглашения с оператором Приложения и использования функций Приложения (ст. 6 ФЗ-152 «О персональных данных» — обработка необходима для исполнения договора, стороной которого является субъект данных), а также на основании согласия пользователя с политикой при продолжении использования функций, требующих передачи текста на сервер.

5. Передача третьим лицам

Текст ваших запросов к функциям, использующим искусственный интеллект, может передаваться провайдеру GigaChat (Сбер) исключительно для генерации ответа и не используется ими для независимой рассылки рекламы со стороны Приложения. Хостинг и база данных размещаются у инфраструктурного провайдера, выбранного оператором (например, хостинг-провайдер), с доступом ограниченным задачами эксплуатации Приложения.

6. Срок хранения

Данные хранятся, пока вы пользуетесь Приложением, и удаляются при удалении соответствующих записей функциями Приложения (например, удаление слова или группы), если иное не требуется законом. Резервные копии могут сохраняться ограниченное время у инфраструктурного провайдера в соответствии с его регламентом.

7. Меры защиты

Используется разделение данных по пользователям, доступ к API по проверке параметров запуска VK (при включённом секретном ключе приложения), ограничение размера запросов и частоты обращений, соединение с API по HTTPS. Полный безопасности в сети не гарантирует ни один сервис — не передавайте в чат Приложения пароли и платёжные данные.

8. Ваши права

Вы вправе:

  • запросить уточнение обрабатываемых данных;
  • потребовать удаления ваших данных в объёме, не противоречащем закону (в т.ч. удаление слов и групп через интерфейс);
  • отозвать согласие, прекратив использование Приложения (часть данных может быть сохранена, если закон требует учёт).

Дополнительно можно обратиться через сообщения официального сообщества или контакт, указанный владельцем в описании мини-приложения ВКонтакте.
